# Como contribuir com o perfil

Este repositório contém os arquivos públicos do perfil e da apresentação profissional. Sugestões de organização, acessibilidade, texto ou código de exemplo são bem-vindas.

Abra uma [issue de melhoria](../../issues/new?template=feature_request.yml) descrevendo o arquivo afetado, o problema e o resultado esperado. Não inclua dados pessoais, credenciais, depoimentos ou métricas que não possam ser comprovados.

Pull requests devem explicar o teste realizado e manter o perfil fiel ao trabalho público existente.
